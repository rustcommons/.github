# 🦀 Rust Commons

<img src="assets/rust-commons.svg" width="160" height="160" alt="Rust Commons: an orange crab with a crate-shaped shell">

[profile/README.md](profile/README.md) is the public profile displayed on the
[rustcommons organization page](https://github.com/rustcommons). It states the
organization’s scope and introduces the Linux compatibility and ABI crates,
their dependencies, and a separate compatibility-testing executable.

Maintainers: follow the [documentation conventions](docs/DOCUMENTATION.md) and
use the [requirements index](docs/REQUIREMENTS.md) to trace this repository's
confirmed scope, documentation, and validation gaps. These are documentation
maintenance paths; this repository requires no build or runtime setup.
